v1.5

加入了短期记忆功能，提高了回复时的沉浸感

原理：

在本地按会话保存最近几轮：群/私聊 ID;发送者;对方消息;大肥鱼回复;时间，

下次同一会话收到新消息时，把这些内容一起放进提示词，例如：

[近期对话]:
群友A：你上次说的那家店叫什么？
大肥鱼：叫「山野食堂」，主人说还不错。
群友A：人均多少来着？
